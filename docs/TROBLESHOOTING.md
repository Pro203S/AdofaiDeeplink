# AdofaiDeeplink 문제 해결

## 1. 바이러스가 발견되었다고 떠요.

Windows 검색에 `antivirus`를 검색 후 `바이러스 및 위협 방지`를 눌러주세요.  
발견된 위협을 누른 후 `작업 > 디바이스에서 허용`을 눌러주세요.  

## 2. \*.adofai, \*.adozip에 원래 연결 프로그램이 사라졌어요.

AdofaiDeeplink는 설치 과정에서 \*.adofai, \*.adozip의 연결 프로그램을 덮어씁니다.  
만약 이전 연결 프로그램을 설정하고 싶다면, `\*.adofai 파일 우클릭 > 연결 프로그램`을 눌러 다른 프로그램으로 설정할 수 있습니다.  

## 3. \*.adofai, \*.adozip을 실행해도 얼불춤이 켜지지 않아요.

`*.adofai 파일 우클릭 > 연결 프로그램 > 다른 프로그램 선택`을 눌러 `A Dance of Fire and Ice`를 선택 후 `항상`을 클릭합니다. (아이콘은 기본 응용 프로그램 아이콘이 정상입니다)  

만약 이 과정을 진행해도 실행되지 않을 경우, [Releases](https://github.com/Pro203S/AdofaiDeeplink/releases)에서 `AdofaiDeeplink.exe`를 다운받으신 후, 실행 해 [Remove]를 눌러 모드 삭제 후 다시 설치해주세요.
