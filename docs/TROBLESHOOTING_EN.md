# AdofaiDeeplink Troubleshooting

## 1. Windows says a virus was detected.

Search for `antivirus` in Windows Search and open `Virus & threat protection`.  
Click on the detected threat, then select `Actions > Allow on device`.

**Note:** Only allow the file if you trust it and have verified that it is safe.

## 2. The previous default apps for *.adofai and *.adozip files are gone.

AdofaiDeeplink overrides the default apps for `*.adofai` and `*.adozip` files during installation.

If you want to restore the previous default app, right-click an `*.adofai` file, select `Open with`, and choose another application.

## 3. A Dance of Fire and Ice doesn't launch when opening *.adofai or *.adozip files.

Right-click an `*.adofai` file and select `Open with > Choose another app`.  
Select `A Dance of Fire and Ice`, then click `Always`. (It's normal for the icon to appear as the default application icon.)

If the game still doesn't launch after following these steps, download `AdofaiDeeplink.exe` from [Releases](https://github.com/Pro203S/AdofaiDeeplink/releases), run it, and click `[Remove]` to uninstall the mod. Then reinstall it.
