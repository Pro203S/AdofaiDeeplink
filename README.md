# AdofaiDeeplink

[ENGLISH](./docs/ENGLISH.md) [TROBLESHOOTING](./docs/TROBLESHOOTING.md) [Report Bugs](https://github.com/Pro203S/AdofaiDeeplink/issues)  

얼불춤 관련 파일, `adofai://` 링크를 열 수 있는 모드입니다.  

> [!IMPORTANT]
> 이 모드는 Steam으로 설치된 얼불춤에서만 작동합니다.  
> 이 모드는 Windows 환경에서만 사용할 수 있습니다.

## 설치 방법

1. [Releases](https://github.com/Pro203S/AdofaiDeeplink/releases)에서 `AdofaiDeeplink.exe`를 다운로드하세요. (모드 zip파일은 안받아도 됩니다)
2. `AdofaiDeeplink.exe`를 실행하면 모드까지 자동으로 설치됩니다.

## 사용법

### adofai:// 로 된 링크 열기

1. `adofai://open?url=<레벨의 URL>`로 레벨을 열 수 있습니다.
2. `adofai://updateMod`로 모드를 업데이트 할 수 있습니다.
2. `adofai://uninstall`로 모드를 삭제 할 수 있습니다.

> [!IMPORTANT]
> 레벨의 URL은 **URL로 열기**로 열 수 있는 레벨이여야합니다.  
> 예시: `cdn.discordapp.com` 등의 링크

### \*.adofai, \*.adozip 파일 열기

1. 맵 폴더에서 확장자가 `.adofai`인 파일을 찾습니다.
2. 더블 클릭하면 얼불춤이 자동으로 실행됩니다.

> [!TIP]
> 자동으로 얼불춤이 열리지 않는다면, 확장자가 `.adofai`인 파일을 우클릭 한 후, `연결 프로그램 > A Dance of Fire and Ice`를 눌러주세요.

### \*.zip 파일 열기

1. `.zip` 압축 파일을 우클릭 합니다.  
2. `Open with ADOFAI`를 클릭합니다.  

> [!NOTE]
> Windows 11 사용자는 `더 많은 옵션 보기`를 눌러야 할 수 있습니다.

## 모드 삭제

1. `Win+R`을 눌러 실행 창을 열어주세요.
2. `%localappdata%\Pro203S\AdofaiDeeplink`를 입력 후 엔터를 눌러주세요.
3. `AdofaiDeeplink.exe`를 실행해주세요.
4. [Remove]를 눌러 제거합니다.

## 사용 시 주의할 점

* 원래 `.adofai`, `.adozip`의 연결 프로그램을 설정해두셨다면 AdofaiDeeplink로 덮어씌워질 수 있습니다.
* 모드만 설치하면 아무것도 되지 않습니다. 반드시 `AdofaiDeeplink.exe`로 설치해주세요.
