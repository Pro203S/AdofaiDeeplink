# AdofaiDeeplink v0.1.0

> 아직 테스트중입니다. 버그가 발생할 수 있으며 버그가 발생했을 경우, [Issues](https://github.com/Pro203S/AdofaiDeeplink/issues)에 제보해주시면 대단히 감사하겠습니다.

\*.adofai, \*.adozip 등의 파일을 더블 클릭만으로 얼불춤에서 열 수 있습니다.  
또한 \*.zip 파일의 우클릭 메뉴에 `Open with ADOFAI`를 추가합니다.  

자세한 사항은 [README.md](https://github.com/Pro203S/AdofaiDeeplink)를 참고해주세요.

--- english ---

> This mod is still being tested, so bugs may occur. If you encounter any bugs, we would greatly appreciate it if you could report them on [Issues](https://github.com/Pro203S/AdofaiDeeplink/issues).

You can open files such as \*.adofai and \*.adozip directly in A Dance of Fire and Ice by simply double-clicking them.

It also adds an `Open with ADOFAI` option to the right-click context menu for \*.zip files.

For more details, please refer to the [README.md](https://github.com/Pro203S/AdofaiDeeplink/blob/master/docs/ENGLISH.md).

Download: <https://github.com/Pro203S/AdofaiDeeplink/releases>
